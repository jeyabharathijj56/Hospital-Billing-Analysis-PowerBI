# 🏥 Hospital Data Analytics using Power BI

## 📌 Project Overview
This project focuses on analyzing hospital operations and performance using Microsoft Power BI. It provides interactive dashboards to understand patient information, doctor performance, appointments, treatments, and hospital billing.

## 🎯 Project Objectives
- Analyze hospital patient data.
- Monitor doctor performance.
- Track appointment status and trends.
- Analyze treatment types and costs.
- Understand hospital revenue and outstanding payments.
- Generate meaningful business insights.

## 📊 Dashboards Created

### 1. Hospital Overview
- Total Patients
- Total Doctors
- Total Revenue
- Total Payments Received
- Total Appointments
- Monthly Revenue Trends

### 2. Patient Analytics
- Patient Demographics
- Gender-wise Analysis
- Age Group Analysis
- Patient Registration Trends
- Treatment Expenditure

### 3. Doctor Performance Analytics
- Doctor-wise Appointment Analysis
- Average Appointments per Doctor
- Completed Appointments
- Consultation Revenue by Doctor
- Doctor Completion Rate

### 4. Appointment Analytics
- Appointment Completion Rate
- Cancelled and Missed Appointments
- Daily Appointment Volume
- Monthly Appointment Trends
- Hourly Appointment Distribution

### 5. Treatment and Diagnosis Analytics
- Treatment Volume by Type
- Department-wise Treatment Analysis
- Treatment Expenditure
- Average Treatment Cost

### 6. Billing and Revenue Analytics
- Total Billing Amount
- Collected Revenue
- Outstanding Balance
- Payment Method Distribution
- Monthly Billing Trends
- Top Patients by Outstanding Balance

## 🛠️ Tools & Technologies

- Data Cleaning and Transformation
- Data Visualization
